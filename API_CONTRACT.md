# Implementation contract (MVP)
All /api routes require same-origin local session cookie or X-Clip-Token. JSON except uploads. Errors: {detail: string}. SQLite is source of truth; one heavy worker serializes all model/media jobs. Never fabricate model/metric success. Default Instagram publishing and ads disabled. Tokens stay in OS keychain, never DB/browser/API responses.

- GET /api/system -> {platform,apple_silicon,memory_gb,free_disk_gb,ffmpeg,ffprobe,whisper,model_runtime,desktop,data_dir}
- GET /api/settings -> {brand,objective,language,autonomy,publishing_enabled,ads_enabled,daily_budget,total_budget,graph_version}; defaults discovery/en/review/false/false/0/0/v22.0. PUT same editable fields, objective enum discovery awareness engagement followers traffic leads sales custom; custom_event optional. Capabilities do not imply integration available.
- GET /api/models -> [{id,name,repo,kind,license,estimated_gb,installed,status}]; POST /api/models/{id}/download {accept_license:true} -> job; DELETE /api/models/{id} unloaded queued check. IDs qwen-small,qwen-large,whisper-turbo,kokoro. POST /api/runtime/setup -> job; POST /api/inference {prompt,model_id:"qwen-small"} -> job with result.output.
- GET /api/jobs -> job[]; POST /api/jobs/{id}/cancel -> job. Job: {id,kind,status:queued|running|completed|failed|cancelled,progress:0..100,message,error,result,context,created_at,updated_at,started_at?,finished_at?}; result object nullable; finished_at set on every terminal state.
- POST /api/videos multipart file -> video; GET /api/videos -> video[]; DELETE /api/videos/{id}. Video {id,name,duration,width,height,size,created_at,transcript,analysis,status}; GET /api/videos/{id}/media for playback.
- POST /api/videos/{id}/transcribe {} -> job; POST /api/videos/{id}/analyze {model_id?} -> job; POST /api/videos/{id}/render {start,end,hook,caption,objective,subtitles:true,format:"vertical"} -> job result.clip_id. Analyze result candidates [{start,end,hook,caption,reason,objective}], from local model, validated boundaries. Without model, manual editor works.
- GET /api/clips -> clip[]; PUT /api/clips/{id} {approved?,caption?,hook?}; DELETE /api/clips/{id}; GET /api/clips/{id}/media; GET /api/clips/{id}/download. Clip {id,video_id,name,start,end,hook,caption,objective,approved,created_at,status,instagram_media_id,published_at}.
- GET /api/instagram/status -> {connected,account?,publishing_available,ads_available,requirements:[],oauth_configured}. POST /api/instagram/connect {access_token,account_id?} -> status (inspect actual Meta account, no fake success); DELETE disconnect. POST /api/instagram/oauth/start -> {url} if configured; callback actual endpoint /api/instagram/oauth/callback.
- POST /api/clips/{id}/publish {public_video_url} -> job. Public HTTPS asset hosting required, no local URL uploads promised. Validate approved clip + setting publishing_enabled + account. Endpoint fetches actual Media container and polls; async.
- POST /api/instagram/sync -> job importing only real media metrics.
- GET /api/analytics -> {videos:[{clip_id,name,objective,organic:{metric:number|null},paid:{metric:number|null},attribution,source,updated_at}],summary:{},notes:[]} unknown is null, not zero.
- POST /api/analytics/events {clip_id,event:lead|purchase|visit|follow|custom,value?,revenue?,source:"manual",occurred_at?} records explicitly manual observations (not claimed causal). GET? events contained in analytics.
- POST /api/clips/{id}/feedback {rating:1..5,notes} -> feedback.
- Ads must be gated: no unattended launch, no simulated running campaigns. Can expose settings/capability setup and explicit preflight. Paid insights only if Meta ad account is configured. No credentials in frontend persistence.

## Clip versions, technical checks and exports

- Render request (direct `POST /api/videos/{id}/render` and campaign `POST /api/campaigns/{id}/render`) adds optional fields: `opening_treatment` (`text_overlay`|`cold_open`, plus `none` for direct renders; omitted keeps the legacy rule: overlay when `hook_overlay` and a hook exist), `cold_open_start`/`cold_open_end` (source seconds, 0.5–10 s, played before the main range; replaces the text overlay), `focus_x` (0..1 horizontal crop focus for `fill`), `changed_variable` (label for a variant comparison, e.g. `opening_treatment`), `parent_clip_id` + `change_reason` (create a linked revision), `retry_of_job_id` (explicit retry of a failed/cancelled render). 422: invalid opening/cold-open range, revision without reason, revision that changes no edit decision, parent from another source/campaign/profile, campaign clip revised through the direct route. 409: captions requested for a source with audio but no transcript; retry of a non-failed job, of an already-retried job, or beyond 3 attempts.
- `PUT /api/videos/{id}/transcript {format:srt|vtt|json, content, language?}` -> video. Imports a transcript (fallback or correction for local Whisper). Cues must lie within the source; text is stored verbatim. 409 while the source has a running task. Video gains `transcript_origin` (`generated`|`imported`), `transcript_model`, `transcript_updated_at`.
- Every render runs playback/format checks (full decode, MP4 with metadata first, H.264 yuv420p 1080×1920 30 fps, duration within one frame per cut boundary, AAC audio when the source has audio, audible level and A/V length as warnings) and caption checks (transcript-sourced only, timing, display time, length). A playback/format failure fails the job and saves no clip; caption issues are flagged, not blocking.
- Clip adds: `edit_plan`, `opening_treatment`, `changed_variable`, `source_segments[{role:cold_open|main,start,end}]`, `transcript_origin`, `caption_cues`, `focus_x`, `technical_checks{checked_at,playback_format[],captions[],playback_format_passed,caption_issues[]}` (each check `{id,label,status:pass|fail|warn|not_applicable,detail}`), `sha256`, `bytes`, `render_receipt{job_id,started_at,finished_at,elapsed_seconds,attempt,retry_of_job_id,ffmpeg_version,encoder,cost{status:"known",amount:0,currency,basis,excluded[]}}`, `parent_clip_id`, `root_clip_id`, `revision_number`, `change_reason`, `plan_changes[{field,before,after}]`, `approved_at`. Rendered files are read-only; changes create new revisions, which start unapproved. DELETE /api/clips/{id} returns 409 when later revisions build on it or it was exported.
- `POST /api/clips/{id}/export` -> 201 `{id,clip_id,video_id,campaign_id,profile_id,revision_number,sha256,bytes,file,location,checksum_recorded_at_render,created_at,manifest}`. Requires an approved clip (409 otherwise) whose file still matches its recorded checksum (409 on mismatch). Writes `exports/<id>/` with the byte-identical MP4, `captions.srt` when burned captions exist, and `manifest.json` (`clip-factory/export-manifest@1`: video, clip lineage, review, source, source_segments, edit_plan, opening_treatment, changed_variable, strategy, technical_checks, render_receipt, post_copy). `GET /api/exports?clip_id=` lists exports; `GET /api/exports/{id}/manifest`, `GET /api/exports/{id}/download`.

Frontend React/Vite, no external remote assets. Desktop pywebview wraps same origin FastAPI. Main launcher runs loopback random port, browser fallback explicit --browser. macOS double-click launcher and CI .app packaging. API media playback same-origin cookie supports range response. Local storage is only UI preferences (no tokens).

## Local campaign context

- `/api/profiles`: list/create local profiles; `/api/profiles/{id}`: get/update, with production history on reads. Goal-directed profiles require a user-selected primary metric. Profiles are not Meta account connections.
- `/api/campaigns`: list/create; `/{id}`: get/update editable brief, source/profile membership. Historical membership cannot be silently removed.
- `/{id}/strategies`: list/create immutable proposed versions. `/{id}/strategies/{version}/approve`, `/reject`, `/restore` provide explicit decisions; restore proposes selected-profile direction rather than auto-activating it. Proposals identify their base version; stale approvals conflict.
- `/{id}/observations`: append/list scoped manual-import observations for an approved clip, retaining source publication, unit, nullable value, timezone-bearing window/collection time, notes and reviewed clip snapshot. Unknown is never coerced to zero.
- `/{id}/learning`: proposes a hypothesis and direction for one profile from validated known-value evidence. Retained references are merged and scope-checked. No winner or causal lift is inferred.
- `/{id}/render`, `/{id}/produce`: queue deterministic or agent production with immutable approved context. UI requests include `expected_strategy_version_id`; mismatches return 409 before queueing. Direct ranges are preserved with recorded deviations. Burned hook changes require a new render, not metadata relabeling.

Here `/{id}` routes are under `/api/campaigns`. All routes use the existing authenticated same-origin session. No action grants publication/spend permission. The heavy worker serializes runtime setup, model inference and media work; model **downloads** use their separate bounded three-worker lane.
