# Implementation contract (MVP)
All /api routes require same-origin local session cookie or X-Clip-Token. JSON except uploads. Errors: {detail: string}. SQLite is source of truth; one heavy worker serializes all model/media jobs. Never fabricate model/metric success. Default Instagram publishing and ads disabled. Tokens stay in OS keychain, never DB/browser/API responses.

- GET /api/system -> {platform,apple_silicon,memory_gb,free_disk_gb,ffmpeg,ffprobe,whisper,model_runtime,desktop,data_dir}
- GET /api/settings -> {brand,objective,language,autonomy,publishing_enabled,ads_enabled,daily_budget,total_budget,graph_version}; defaults discovery/en/review/false/false/0/0/v22.0. PUT same editable fields, objective enum discovery awareness engagement followers traffic leads sales custom; custom_event optional. Capabilities do not imply integration available.
- GET /api/models -> [{id,name,repo,kind,license,estimated_gb,installed,status}]; POST /api/models/{id}/download {accept_license:true} -> job; DELETE /api/models/{id} unloaded queued check. IDs qwen-small,qwen-large,whisper-turbo,kokoro. POST /api/runtime/setup -> job; POST /api/inference {prompt,model_id:"qwen-small"} -> job with result.output.
- GET /api/jobs -> job[]; POST /api/jobs/{id}/cancel -> job. Job: {id,kind,status:queued|running|completed|failed|cancelled,progress:0..100,message,error,result,created_at,updated_at}; result object nullable.
- POST /api/videos multipart file -> video; GET /api/videos -> video[]; DELETE /api/videos/{id}. Video {id,name,duration,width,height,size,created_at,transcript,analysis,status}; GET /api/videos/{id}/media for playback.
- POST /api/videos/{id}/transcribe {} -> job; POST /api/videos/{id}/analyze {model_id?} -> job; POST /api/videos/{id}/render {start,end,hook,caption,objective,subtitles:true,format:"vertical"} -> job result.clip_id. Analyze result candidates [{start,end,hook,caption,reason,objective}], from local model, validated boundaries. Without model, manual editor works.
- GET /api/clips -> clip[]; PUT /api/clips/{id} {approved?,caption?,hook?}; DELETE /api/clips/{id}; GET /api/clips/{id}/media; GET /api/clips/{id}/download. Clip {id,video_id,name,start,end,hook,caption,objective,approved,created_at,status,instagram_media_id,published_at}.
- GET /api/instagram/status -> {connected,account?,publishing_available,ads_available,requirements:[],oauth_configured}. POST /api/instagram/connect {access_token,account_id?} -> status (inspect actual Meta account, no fake success); DELETE disconnect. POST /api/instagram/oauth/start -> {url} if configured; callback actual endpoint /api/instagram/oauth/callback.
- POST /api/clips/{id}/publish {public_video_url} -> job. Public HTTPS asset hosting required, no local URL uploads promised. Validate approved clip + setting publishing_enabled + account. Endpoint fetches actual Media container and polls; async.
- POST /api/instagram/sync -> job importing only real media metrics.
- GET /api/analytics -> {videos:[{clip_id,name,objective,organic:{metric:number|null},paid:{metric:number|null},attribution,source,updated_at}],summary:{},notes:[]} unknown is null, not zero.
- POST /api/analytics/events {clip_id,event:lead|purchase|visit|follow|custom,value?,revenue?,source:"manual",occurred_at?} records explicitly manual observations (not claimed causal). GET? events contained in analytics.
- POST /api/clips/{id}/feedback {rating:1..5,notes} -> feedback.
- Ads must be gated: no unattended launch, no simulated running campaigns. Can expose settings/capability setup and explicit preflight. Paid insights only if Meta ad account is configured. No credentials in frontend persistence.

Frontend React/Vite, no external remote assets. Desktop pywebview wraps same origin FastAPI. Main launcher runs loopback random port, browser fallback explicit --browser. macOS double-click launcher and CI .app packaging. API media playback same-origin cookie supports range response. Local storage is only UI preferences (no tokens).
