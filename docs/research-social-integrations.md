# TikTok, YouTube and optional Supabase setup

Checked primary documentation **2026-11-14**. Research only: neither channel is implemented/connected by this work; no accounts, scopes, projects, uploads or charges were created.

## Recommendation

**YouTube is the easier next channel**: managed Composio OAuth plus owned-channel analytics. **TikTok has substantial app/audit gates**, even though its toolkit exists. Keep the current Mac database for the working local loop; add Supabase when shared accounts/cloud persistence/public storage are an actual requirement. These are recommendations from the documented capabilities, not verified grants for our accounts.

## Constraints that affect this product

**TikTok:** unaudited Direct Post is SELF_ONLY, at most five users/day, with private accounts. A separate per-creator cap is typically around 15 posts/day, shared across API clients. Critically, Direct Post guidelines disallow an app limited to privately uploading to accounts operated by its own team, and disallow copying arbitrary other-platform content. A broader creator product and original/authorized source material matter. Creator identity, current privacy options, editable metadata, explicit upload consent and publish-status reconciliation must be visible; SDK access does not waive these requirements. [Official sharing guidelines](https://developers.tiktok.com/docs/en/content-sharing-guidelines).

TikTok custom OAuth needs a customer-controlled verified callback domain; do not try to host verification files on Composio's shared domain. Request only scopes TikTok approved for that app. The technical toolkit/KB contradict a generic Composio marketing page claiming managed TikTok OAuth; use the technical docs and inspect the chosen auth config. [Composio TikTok guide](https://docs.composio.dev/kb/guide/toolkits-tiktok).

**YouTube:** request upload and analytics grants independently; an upload-only connection is not analytics authorization. Current upload documentation says omitted privacy defaults public and no longer describes unverified uploads as private-only; old revision-history entries describe the former restriction. Therefore do not use an old private-sandbox assumption as an approval gate. Set privacy explicitly and verify the actual account/project. Current documented quota is 100 upload calls/day, 100 search calls/day and 10,000 units/day for other endpoints; the selected project's actual console limits remain authoritative. [Current upload method](https://developers.google.com/youtube/data/reference/rest/v3/videos/insert), [current quota guide](https://developers.google.com/youtube/v3/guides/quota_and_compliance_audits).

Before implementation, inspect the **exact current Composio action schemas** and auth-config scopes. Toolkit presence proves availability in the catalog, not every scope being granted or an upload working. No private/granted schema execution was attempted here.

## Supabase vs the local Mac database

Supabase provides managed **PostgreSQL** plus Auth/Storage and related services; it is not merely a database filename replacement. For this single-operator local-first Mac app, retaining SQLite is the smaller reliable choice. Later use Supabase for cross-device/team records, authenticated cloud state and deliberate asset hosting; it does not by itself move local FFmpeg/Whisper/model execution into an always-running worker. This architecture recommendation is an inference from our local runtime and Supabase's separate cloud/local services. [Database connection options](https://supabase.com/docs/guides/database/connecting-to-postgres), [local development](https://supabase.com/docs/guides/local-development).

Free plan currently permits **two active projects**, 500 MB database and 1 GB file storage, with inactivity pausing after a week. The project limit is shared across organizations where the user is Owner/Admin; an existing paid organization is not a free sandbox. Keep this experiment in a Free organization and avoid upgrades/add-ons. No credit-card-free guarantee was found in the inspected pricing text, and no resource/billing action was performed. [Pricing](https://supabase.com/pricing), [billing/account rules](https://supabase.com/docs/guides/platform/billing-on-supabase), [pausing](https://supabase.com/docs/guides/platform/free-project-pausing).

Choose region near the future worker/users, with required data residency in mind; exact US West, Frankfurt or Mumbai are options, not an automatic recommendation based on the laptop's location. Changing a project's region requires a new project and migration. Never embed database passwords or secret/service-role keys in a distributed Mac frontend; use user authentication/RLS and an appropriate server boundary. [Regions](https://supabase.com/docs/guides/platform/regions), [region changes](https://supabase.com/kb/troubleshooting/change-project-region-eWJo5Z), [API-key boundaries](https://supabase.com/docs/guides/getting-started/api-keys).
