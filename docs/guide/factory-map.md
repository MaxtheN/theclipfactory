# Factory map

The **Factory map** is a live picture of the factory while it works. It opens after your first **Find clips** and can be opened again from Factory at any time.

## Stations

The map has five groups of stations, from footage in to lessons learned. Each station is a real job or step, shown as it happens. Select one to see its counts and recent items.

| Group | Station | What it is doing |
|---|---|---|
| Understand | Footage in | Taking in the episode |
| | Listen | Transcribing speech, or using the transcript you imported |
| | Watch | Watching the episode once and building a storyboard of scenes |
| Create | Scout swarm | One scout per stretch of the episode, proposing moments |
| | Brief check | Checking moments against your must-avoid list and key messages |
| | Editor | Hook first, then captions and cuts |
| Judge | Critic + quality gate | Checking each clip, ranking, merging near-duplicates, applying the quality floor |
| | You approve | Clips waiting for you, and clips you approved |
| Ship | Post | Approved clips posted from the app |
| | Measure | The 3-day and 6-day measurement windows |
| Learn | Strategist | Patterns in craft, clip picking and timing |
| | Style rules update | Proposed rule changes, which you approve |
| | Factory builder | Editing styles the factory cannot render yet, turned into reviewed code changes (see [Results](results.md#factory-upgrades)) |

The quality gate's panel shows how many clips were ranked, above the bar, **below the bar (kept, not deleted)**, merged as near-duplicates, and picked as top picks.

## Reading the map honestly

- The map shows the queue as it really is. With [one heavy worker](factory.md#one-heavy-worker), only one heavy station is lit at a time; the others are waiting, not stuck.
- Closing the map does not stop anything. Cancel work from **Activity** (⌘K / Ctrl+K → Activity). Cancelling an active step may take a moment to finish.
- Times shown are processing time for that step. They do not include time spent in the queue or your own review time.
