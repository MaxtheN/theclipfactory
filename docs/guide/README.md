# Growth Factory user guide

Growth Factory turns long videos (podcast episodes, streams, talks) into short clips. You set the creative intent; agents on your computer find moments, edit, check their own work and suggest what to try next. You approve every clip before it is exported or posted.

The app keeps its labels short. This guide holds the longer explanations: how each part works, what data leaves your computer, and what the numbers can and cannot tell you.
