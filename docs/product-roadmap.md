# One factory, two production lines

Source: Kartik’s notebook sketch IMG_0257.HEIC, reviewed2026-11-14. Treat it as product direction, not implemented capability.

## Finish the podcast line now

Audience/goal onboarding → upload → grounded moment/creative choices → edited drafts → human approval → account-specific publishing → engagement observations → one changed creative hypothesis → a real new draft.

Connect Instagram first. YouTube is the next integration; TikTok has its own developer/OAuth/audit gates. Double down only when the chosen metric and evidence support it. No automatic overall winner from agent quality scores or missing observations.

Acceptance: one real playable source-backed clip, exact review/export and publication mapping, persistent observation/work/experiment state, a concrete changed render and honest failure/recovery. Account/provider verification and complete publication execution remain live implementation gates; do not claim dashboard connections are app bindings.

## Brand and digital media head later

Product/catalog and landing-page context → multiple creative formats → reviewed distribution/paid proposals → conversion attribution and currency/window-aware ROAS → budget-limited experiments → new creative formats.

Shopify, landing pages, paid media buying and ROAS are expansion points. They do not enter the current podcast demo’s critical path. No ad activation or spending is authorized by this roadmap.

## Shared foundation

Brand/audience memory, explicit account authorization, versioned creative policy, agent/job ledger, source/output lineage, immutable evidence, experiment receipts and human publication control. Agents adapt policy and editing decisions; this is not self-training model weights.

Supabase’s owner-private metadata foundation is prepared. App Auth/sync and hosted workers are still separate from the working local SQLite execution layer.

## Account and release roadmap — later

- Signup/sign-in for Growth Factory users (separate from Instagram OAuth); browser-based PKCE flow and secure desktop session storage.
- Supabase Auth, owner-scoped cloud synchronization, offline reconciliation and explicit team membership/invitations.
- Safe field-by-field metadata projection, version conflict protocol and evidence retention/deletion rules before uploading local state.
- Hosted collection/learning workers for operation while the Mac app is closed.
- Signed/notarized Mac distribution and single-instance coordination.

The database foundation is applied; these application features are intentionally later work. No signup screen or working cloud sync is claimed by this milestone.
