## Product flow

**Onboard → Factory → produce → review exact clip → approve/export → Results → approve one next test.** Library holds footage and edits. Models, settings, integrations, full version history, and diagnostic ledgers belong in accessible secondary tools. Keep these real controls available while adapting them to the new design.

The current integrated `GrowthApp` still mounts the existing operational `App` through **Workspace tools** (`growth/GrowthApp.tsx:235–252`); the old capabilities are therefore secondary, not deleted. New `FactoryHome`, `Library`, and `Onboarding` files exist but were not yet mounted by that shell at audit time. Preserve this escape hatch until feature parity is verified. Master `App.tsx:11–20` exposes Campaigns / Dashboard / Library / Factory / Models / Instagram / Results / Settings.

## Build/review priorities

1. **First real render:** scoped upload/attach → approved direction → manual or real agent route → real queue → exact clip playback → critic eligibility + human approval → verified MP4 export. Keep backend failure/identity evidence visible.
2. **Protect capabilities while simplifying:** keep Workspace tools reachable; add direct contextual links to runtime/model blockers, run ledger, transcript detail, strategy history and integrations. Do not transplant the old all-global Factory clip grid into a scoped workspace.
3. **Make Factory/Library navigation truthful:** new workspace creation must not inherit an old workspace/source; profile/source/clip IDs drive actions, not array-first fallback. Open exact clip from Library. “Find clips” preserves agent intent across navigation.
4. **Show the learning loop honestly:** actual selected-profile goal → cited scoped observation → one concrete saved change → exact approval → next production using that change. Add comparison/connected insights only with provenance and immutable scope; no measured growth claim from agent confidence.
5. **Defer polished wrappers, not working controls:** model installation, full version restoration, baseline comparison, platform insight sync, paid preflight and optional narration can remain in operational tools for this demo. Mark precedent research, automatic follow-up, public asset hosting and ad optimization as unimplemented rather than illustrative actions.

This map verifies source/UI contracts only. It does not certify installed models, live Meta permissions, provider availability, actual render success, or the final in-progress shell wiring.
