# Demo acceptance

The promise: a small team can turn footage into reviewed clips, with the decisions and next experiment retained in one workspace.

- **Onboarding:** save the podcast/brand audience, objective and constraints once; reopening restores the selected workspace. Failed saves keep inputs and confirmed identities, without duplicate profiles/uploads.
- **Production:** upload real footage, approve its direction, run the actual selected local model, and expose real tasks, errors and output IDs. A completed job must resolve to actual playable vertical files.
- **Variants:** compare two explicit openings on the same moment. Show the declared variable and source references.
- **Revision:** change a real range/opening/crop/caption decision, retain the parent file, and require fresh review of the child.
- **Review/export:** distinguish technical checks from critique and human acceptance; export the exact approved file with checksum and manifest. No simulated clip is a deliverable.
- **Learning:** import a real observation with exact publication/account/window. Show the hypothesis, current-versus-proposed rule, explicit saved approval, then an actual subsequent edit using it. Preserve the other profile.
- **Impact:** record elapsed time, active human minutes, accepted count, revision count and known costs/exclusions. Compare matched scope and quality with a manual baseline before claiming a percentage saving.
- **Honesty:** label prepared clips and historical evidence. No unsupported winner, ROAS lift, autonomous reference research, live Instagram connection or unattended three-day follow-up claim.

Current technical evidence includes three fixed-range All-In diagnostic outputs with linked revision and byte-verified exports; real Whisper transcription of a60-second excerpt; actual image-input Qwen inference; and a real local baseline producing three captioned clips. The campaign team run also passed with a captioned, critic-passing draft. Its intro fragment is execution proof only; human editorial acceptance, fresh audience lift and the matched human-effort benchmark remain separate gates.
