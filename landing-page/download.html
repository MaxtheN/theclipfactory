Your processing choices

Local-first.
Cloud when you choose.

Keep the route visible. A local workspace does not mean every connected action stays on the device.

Local media and supported models

The app stores its operational state and media on your Mac. Local model readiness depends on memory, disk space and the selected task. Models are downloaded separately.

Optional cloud agents

Configured cloud roles send their relevant inputs to the selected provider. Sharing still frames has a separate setting. Provider usage can incur costs.

Connected publication

Instagram needs a verified account, publishing permissions and hosted media it can fetch. Posting and scheduling remain distinct from generating a clip; scheduled work needs the app open.

Before you start

Useful details.

Is there an installer I can download now?

Yes: download the Mac app (Apple Silicon). It is an early preview, signed locally and not yet notarized, so the first launch needs right-click → Open. You can also run it from source below.

Do I need a large local model?

No single model fits every machine or task. Review memory and disk requirements, use the app's readiness checks and choose supported local or cloud routing. Do not download a larger model simply because it appears in the catalog.

Which FFmpeg build do I need?

Use a build with caption support, including libass, plus the filters required by your edits. The Mac source setup can offer Homebrew's ffmpeg-full. FFmpeg is a separate prerequisite, not bundled model software.

Can I see the workflow first?

Start with the product walkthrough and learning guide. Website illustrations explain the workflow; real generation and the labeled rehearsal run inside the Mac app.
